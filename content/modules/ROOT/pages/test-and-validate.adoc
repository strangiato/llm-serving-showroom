= Testing and Validation Your LLM
:navtitle: Testing and Validation Your LLM

In this exercise you will validate the deployment from xref:deploying-llm.adoc[Deploying an LLM] and send inference requests to the model using the OpenAI-compatible API exposed by the model server.

== Get the external endpoint URL

The model is exposed through the cluster Gateway on an external endpoint that is accessible from inside or outside the cluster.

. From the OpenShift AI Dashboard, open the *Projects* menu and select your project (`user#-model-server`).  Navigate to the *Deployments* tab and find the deployed model (`llama-3.2-1b-instruct`).  Confirm that the *Status* of the deployment shows ready.

. Click the *Internal and external endpoint* link for the deployed model.  The *Inference endpoints* dialog opens and shows the endpoint URLs for the model.
+
image::test-and-validate/endpoint-url.png[The Inference endpoints dialog showing the external endpoint URL of the model,link=self,window=blank,width=700]

. Copy the external endpoint URL using the *Copy* button next to the URL.  The URL contains your project name and the model name:
+
----
http://<gateway-host>/user#-model-server/llama-32-1b-instruct
----

. Export the copied URL as an environment variable in your terminal so that it can be used in the requests that follow:
+
[source,role="execute"]
----
export ENDPOINT_URL=<paste the copied endpoint URL here>
----

== Test the endpoint

The model server exposes an OpenAI-compatible REST API.  Validate the deployment by listing the models on the endpoint and sending a chat completion request.

. List the models available on the endpoint:
+
[source,role="execute"]
----
curl -s $ENDPOINT_URL/v1/models
----
+
The response lists the model served by the model server:
+
[source]
----
{"object":"list","data":[{"id":"llama-32-1b-instruct","object":"model","created":1793128935,"owned_by":"vllm","root":"/mnt/models","max_model_len":131072}, ...]}
----

. Send a chat completion request to the model:
+
[source,role="execute"]
----
curl -s $ENDPOINT_URL/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "llama-32-1b-instruct",
    "messages": [
      {
        "role": "user",
        "content": "Where is Red Hat headquarters located?"
      }
    ]
  }'
----
+
The response contains the reply generated by the model:
+
[source]
----
{"id":"chatcmpl-...","object":"chat.completion","created":...,"model":"llama-32-1b-instruct","choices":[{"index":0,"message":{"role":"assistant","content":"Red Hat's headquarters is located in Raleigh, North Carolina, United States."},"finish_reason":"stop"}],"usage":{...}}
----

The deployment has now been validated end to end: the external endpoint is reachable, the model is served, and the model responds to inference requests.
